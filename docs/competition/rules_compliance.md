## 6. 경기 운영 절차 (소프트웨어 시작 흐름)

1. 경기장 공개 전: PC와 로봇을 주최 측 Wi-Fi 공유기에 연결해 제출 (1.5, 3.1.5). 이후 수정·버튼 조작 금지.
   → 행사장에는 학교 Wi-Fi가 없으므로 Pi에 접속할 네트워크를 미리 준비한다 (`docs/bringup_checklist.md`).
2. 임무 시작 전: 심판 감독하에 PC를 돌려받아 **실행 명령만** 무선으로 전달 (1.6). 로봇에 붙인 **시작 버튼**도 허용 (Q2·Q11).
3. 시작 신호: 지정 위치에서 로봇을 구동하고 원격 PC 로그아웃, 경기장 20 cm 밖으로 이탈 (3.2, 3.5.2).
4. 시작 후: 로봇이 무선을 끄고 끝까지 혼자 동작 (1.3, Q1).
5. 첫 임무 전 충전 시간 없음 → **충전해서 가져간다**. 자리마다 콘센트는 있음 (Q14). 배터리 교체는 임무 사이에만 (2.2.5).
